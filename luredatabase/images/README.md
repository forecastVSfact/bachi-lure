# ルアー画像フォルダ

ここにルアー画像を置き、次のコマンドで Supabase にアップロードします。

```bash
npm run import:images
```

## ファイル名のルール

**ルアー名と同じファイル名**にしてください（拡張子のみ違う）。

| ルアー名（Excel） | ファイル名の例 |
|------------------|----------------|
| ノガレ120F | `ノガレ120F.jpg` |
| ベイルーフ マニック95 | `ベイルーフ マニック95.png` |

対応形式: `.jpg` `.jpeg` `.png` `.webp` `.gif`

## 注意

- 同名のルアーが DB に複数ある場合はスキップされます（重複整理後に再実行）
- 1ルアー1ファイルが基本（複数枚は Excel の `image_urls` 列か管理画面から）
