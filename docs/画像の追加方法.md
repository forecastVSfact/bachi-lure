# ルアー画像の追加方法

ルアーごとに画像を表示する方法は **2通り** あります。

---

## 一括ダウンロード（Amazon から自動取得）

Excel の Amazon 検索 URL から商品画像を自動取得する場合:

```bash
npm run setup:images
```

`download:images`（取得）と `import:images`（アップロード）を続けて実行します。

---

## 方法A: 画像ファイルをフォルダに置く（おすすめ）

商品写真や撮影した画像ファイルがある場合向けです。

### 1. 画像を置く

`luredatabase/images/` に、**ルアー名と同じファイル名**で保存します。

```
luredatabase/images/ノガレ120F.jpg
luredatabase/images/ベイルーフ マニック95.png
```

### 2. アップロード

```bash
cd "C:\Users\oyabi\OneDrive\デスクトップ\bachi-lure"
npm run import:images
```

成功すると `OK: ノガレ120F <- ノガレ120F.jpg` のように表示されます。

### 3. 確認

```bash
npm run dev
```

一覧・詳細ページに画像が出ます。本番（bachi-lure.com）も同じ DB を見るため、**再デプロイは不要**です。

---

## 方法B: Excel に画像URLを書く

Amazon やメーカーサイトの画像 URL がある場合向けです。

### 1. Excel に列を追加

「ルアーデータ」シートの末尾付近に、例えば次のヘッダーを追加します。

```
画像URL（カンマ区切り可）
(image_urls)
```

1行に1つ、または複数 URL をカンマ区切りで書けます。

### 2. いつもどおり投入

```bash
npm run import:lures
```

`image_urls` 列がある行だけ、画像が DB に登録されます。

---

## 管理画面から1件ずつ追加

`/admin` にログイン → ルアー保存フォームの **外部画像URL（改行区切り）** に URL を入力して保存。

---

## 表示される場所

| 画面 | 表示 |
|------|------|
| ルアー一覧 `/lures` | カード上部のサムネイル |
| ルアー詳細 `/lures/[id]` | 大きい画像（複数枚はサムネ切替） |

画像がないルアーは、これまでどおりプレースホルダー（ルアーのシルエット）が表示されます。

---

## トラブル

### `Skip (no lure match)`

ファイル名がルアー名と一致していません。Excel の `name` と **完全に同じ文字** にしてください。

### `Skip (ambiguous name)`

同じ名前のルアーが DB に複数あります。Supabase で重複を整理してから再実行してください。

### 本番に反映されない

`import:images` / `import:lures` は Supabase を直接更新します。環境変数が本番と同じ Supabase を指していれば、すぐ bachi-lure.com にも反映されます。
