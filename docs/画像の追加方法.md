# ルアー画像の追加方法

**画像は URL リンクではなく、PC のフォルダに保存したファイルをアップロードします。**  
間違った画像やキャッシュの問題を避けるため、この方法だけを使ってください。

---

## 手順

### 1. 画像をフォルダに置く

`luredatabase/images/` に、**ルアー名と同じファイル名**で保存します。

```
luredatabase/images/ノガレ120F.jpg
luredatabase/images/モアザン ミドルアッパー.jpg
luredatabase/images/コアマン アルカリ.jpg
```

対応形式: `.jpg` `.jpeg` `.png` `.webp` `.gif`

> ファイル名は Excel の `name` 列と **完全に同じ** にしてください（`コアマン アルカリ` と `アルカリ` は別ルアーです）。

### 2. Supabase にアップロード

```bash
cd "C:\Users\oyabi\OneDrive\デスクトップ\bachi-lure"
npm run import:images
```

**一部だけ差し替えるとき:**

```bash
npm run import:images:only -- "モアザン ミドルアッパー,ワンダー60"
```

成功例: `OK: ノガレ120F (905c1a5a…) <- ノガレ120F.jpg`

### 3. 確認

```bash
npm run dev
```

→ http://localhost:3000/lures  

本番（bachi-lure.com）も同じ DB を参照するため、**コードの再デプロイは不要**です。

---

## 便利なコマンド

| コマンド | 内容 |
|----------|------|
| `npm run images:missing` | フォルダにまだ無いルアー名の一覧 |
| `npm run clear:external-images` | DB に残っている外部 URL を削除（初回1回推奨） |
| `npm run import:images:only -- "名前"` | 指定ルアーだけ再アップロード |

---

## 使わないもの

- Excel の `image_urls` 列 → **無視されます**（`import:lures` では画像を登録しません）
- 管理画面の「外部画像URL」→ サイトには表示されません
- `npm run download:images` / 画像検索の自動取得 → **廃止**（誤った画像の原因になりやすい）

---

## トラブル

### `Skip (no lure match)`

ファイル名がルアー名と一致していません。`npm run images:missing` で正しい名前を確認してください。

### 本番で古い画像のまま

ブラウザのスーパーリロード（Ctrl+Shift+R）。それでもおかしい場合は、フォルダの JPG を正しいものに差し替えて `npm run import:images:only` を再実行してください。
