# ルアーデータの更新手順

このドキュメントは、Excel で管理しているルアーデータをサイト（Supabase）に反映する方法をまとめたものです。

---

## 全体の流れ

1. Excel を編集する
2. `luredatabase/` フォルダに Excel を置く
3. コマンドで DB に投入する
4. 開発サーバーを起動してブラウザで確認する

```
Excel 編集 → npm run import:lures → npm run dev → ブラウザで確認
```

## Excel の編集ルール

### 使うシート

**「ルアーデータ」シート**（1枚目）だけがインポート対象です。  
「入力・値のガイド」シートは参照用で、投入されません。

### 列名

1行目のヘッダーは、括弧内の英字名が DB の項目名になります。例:

- `ルアー名 (name)` → `name`
- `メーカー (maker)` → `maker`
- `バチ種別 … (bachi_types)` → `bachi_types`

**必須項目**（空だとエラーになります）:

| 項目 | 入力例 |
|------|--------|
| name | ノガレ120F |
| maker | ピックアップ |
| lure_type | `floating` または `sinking` |
| swim_posture | `horizontal` / `head_down` / `tail_down` |
| speed_range | `dead_slow` / `slow` / `medium` / `all` |
| casting_distance | `short` / `medium` / `long` |

### バチ種別（複数可）

`bachi_types` は **カンマ区切り** で書きます。

```
river,harbor,kurukuru
```

使える値:

| 値 | 意味 |
|----|------|
| river | 川バチ |
| harbor | 港湾バチ |
| kurukuru | クルクルバチ |
| bottom | 底バチ |

### 速度域が複数ある行

Excel 上で `slow,medium` のように複数書いてある行は、投入時に **`all`（速度問わず）** にまとめられます。

### おすすめ度（rating）

- `1` ～ `5` の数字
- 未評価は `-` または空欄（DB では未設定）

### 管理人コメント

最後の列（括弧なしの「管理人コメント」）も `comment` として取り込みます。

### 画像

ルアーごとの画像は **[画像の追加方法.md](./画像の追加方法.md)** を参照してください。

- **画像ファイル**: `luredatabase/images/` に置いて `npm run import:images`
- **画像URL**: Excel に `(image_urls)` 列を追加して `npm run import:lures`
- **1件ずつ**: 管理画面 `/admin` の「外部画像URL」

## データを DB に反映する（更新の本体）

プロジェクトフォルダで、次を **1コマンド** 実行します。

```bash
npm run import:lures
```

内部では次の処理が自動で行われます。

1. `scripts/xlsx-to-csv.py` … Excel → `luredatabase/lures.csv`
2. `scripts/import-csv.ts` … CSV → Supabase

成功すると、ターミナルに次のような表示が出ます。

```
Wrote 47 rows -> ...\luredatabase\lures.csv
Imported 47 lures from luredatabase/lures.csv
```

件数（`47` など）は Excel の行数に応じて変わります。

### 別名の Excel を使う場合

```bash
python scripts/xlsx-to-csv.py "luredatabase\新しいファイル名.xlsx" "luredatabase\lures.csv"
npm run import:lures:csv
```

### 手順を分けて実行する場合

```bash
python scripts/xlsx-to-csv.py
npm run import:lures:csv
```

## サイトで確認する

データ投入とは別に、**表示確認用**に開発サーバーを起動します。

```bash
npm run dev
```

ターミナルに `Ready` と `http://localhost:3000` が出たら、ブラウザで開きます。

| ページ | URL |
|--------|-----|
| トップ | http://localhost:3000 |
| ルアー一覧 | http://localhost:3000/lures |

**注意**: `npm run dev` を止める（ターミナルを閉じる）と、ブラウザは `Connection Failed` になります。見ている間は起動したままにしてください。

## よくあるトラブル

### `Connection Failed` / 接続できない

→ `npm run dev` が動いていません。上記「サイトで確認する」を実行してください。

### `Missing Supabase env vars`

→ `.env.local` が無い、または `SUPABASE_SERVICE_ROLE_KEY` などが未設定です。

### `Failed to upsert lure`

→ 必須列が空、または `lure_type` などの値がガイドと違う可能性があります。Excel の該当行を確認してください。

### 同じ Excel を何度も `import:lures` したら件数が増える

→ **ルアー名 + メーカー** が同じ行は既存レコードを更新します。  
それでも件数が多いときは、CSV に無いゴミデータが残っている可能性があります。

```bash
npm run audit:lures          # 件数・重複の確認
npm run prune:stray-lures    # CSV に無いルアーを削除
npm run dedupe:lures         # 名前+メーカーが完全一致する重複を1件に
```

### Python が見つからない

→ `python` コマンドが使えるか確認し、`pip install openpyxl` を実行してください。
