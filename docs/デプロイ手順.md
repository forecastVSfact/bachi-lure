# デプロイ手順（Vercel）

本番サイトは [Vercel](https://vercel.com) でホストする想定です。

## 初回セットアップ

1. [vercel.com](https://vercel.com) にログイン
2. **Add New → Project**
3. GitHub の `forecastVSfact/bachi-lure` をインポート
4. Framework Preset: **Next.js**（自動検出）
5. **Environment Variables** に次を追加（Production / Preview / Development すべて）

| 名前 | 値 |
|------|-----|
| `NEXT_PUBLIC_SUPABASE_URL` | Supabase の Project URL |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Supabase の anon public key |
| `SUPABASE_SERVICE_ROLE_KEY` | Supabase の service_role key（管理画面用） |

6. **Deploy** をクリック

## コード更新後のデプロイ

`master` ブランチへ push すると、Vercel が自動で再ビルド・再デプロイします。

```bash
git add .
git commit -m "your message"
git push origin master
```

ローカルから手動デプロイする場合（Vercel CLI ログイン済み）:

```bash
npx vercel --prod
```

## カスタムドメイン（bachi-lure.com）

Vercel プロジェクト → **Settings → Domains** で `bachi-lure.com` を追加し、表示される DNS 設定をドメイン管理画面に反映します。

## 確認

デプロイ完了後、Vercel の **Deployments** タブに表示される URL（例: `https://bachi-lure-xxx.vercel.app`）でルアー一覧が表示されることを確認してください。

データ（ルアー47件）は Supabase に既に入っているため、**環境変数が本番 Supabase を指していれば** デプロイ直後から一覧が表示されます。
